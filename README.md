# Desafio da Tabela Fipe 📈
## Aplicação feita com Java 
![Java](https://img.shields.io/badge/java-%23ED8B00.svg?style=for-the-badge&logo=openjdk&logoColor=white)

* Também foi usado o Spring Boot e Maven🍃
## O que é a Tabela Fipe?🤔
* Significa que é uma tabela proposta pela Fundação Instituto de Pesquisas Econômicas;
* Ou seja, essa tabela fornece informações sobre o veículos e avaliações desses veículos.

## Objetivos dessa Aplicação🎯
* Consumir dados da Api;
* Modelar esses dados de acordo com:
* Modelo, Marca, Valor, Ano do Modelo e Combustível.
* A partir disso, foi feita a interação com o usuário;
* O ojetivo principal foi fazer um modelo mais objetivo para a pessoa fazer sua pesquisa de veículo.
